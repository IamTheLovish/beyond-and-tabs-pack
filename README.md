# Beyond and Tabs - tester pack

A real-time strategy mod for Minecraft Java 1.20.1 (Forge), in testing with friends.

## Install (once)
1. Install Prism Launcher (free): https://prismlauncher.org - sign in with your Minecraft account.
2. In Prism: **Add Instance -> Import**, paste this link, then OK:
   - Windows / Linux / Intel Mac: https://github.com/christiansaab-hue/beyond-and-tabs-pack/releases/download/install/BeyondAndTabs.zip
   - Apple Silicon Mac: https://github.com/christiansaab-hue/beyond-and-tabs-pack/releases/download/install/BeyondAndTabs-mac.zip
3. Click **Launch**. The first start downloads Minecraft, Forge and every mod by itself.

## Updates
